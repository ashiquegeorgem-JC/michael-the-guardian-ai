# PROJECT OVERVIEW

**Academic Title:** Intelligent Log Analysis and Anomaly Detection Using Artificial Intelligence  
**Product Name:** MICHAEL – THE GUARDIAN AI  
**Tagline:** *“Intelligence That Watches. AI That Protects.”*  

---

## 1. Project Background

Modern organizational networks generate millions of log events daily across distributed servers, containers, firewalls, and microservices. Detecting malicious intrusions, lateral movement, data exfiltration, and service disruptions within this flood of data requires rapid, automated analysis. However, security analysts in Security Operations Centers (SOCs) face widespread "alert fatigue," missing critical indicators amidst thousands of non-contextual alerts generated by legacy rule engines.

**MICHAEL – THE GUARDIAN AI** was designed to address this challenge by providing an evidence-driven, explainable, and integrated platform that connects raw log telemetry to higher-level threat intelligence, multi-stage attack chains, and unified investigation contexts.

---

## 2. Cybersecurity Problem & Motivation

1. **Volume and Velocity:** Enterprise systems emit voluminous heterogeneous logs, making manual inspection impossible.
2. **Alert Fatigue:** Static threshold alerts produce immense false positives, causing operational burnout and delayed response.
3. **Context Fragmentation:** Traditional monitoring tools isolate alerts. An authentication failure, an outbound socket connection, and a web error are reported independently, leaving analysts to mentally reconstruct the overarching attack.
4. **Telemetry Deficit Misinterpretation:** Security tools often assume that if an external threat database has no record of an IP or domain, the entity is benign. This leads to critical false-negative classifications.
5. **Lack of Forensic Provenance:** Threat indicators are frequently aggregated without verifiable references back to the raw log lines and session IDs that proved their presence.

---

## 3. Proposed Solution

MICHAEL implements a multi-tier pipeline that transforms unstructured log streams into unified, explainable threat contexts:

```text
Raw Logs ──▶ Parsing & Normalization ──▶ Multi-Model Anomaly Detection
                                                     │
                                                     ▼
SOC UI ◀── Correlation ◀── Threat Intel ◀── Attack Chains & Incidents
```

- **Hybrid Detection:** Couples unsupervised machine learning (Isolation Forest), natural language processing (TF-IDF), and statistical dispersion with deterministic heuristic rules and sliding-window temporal analysis.
- **Incident & Attack Chain Synthesis:** Groups anomalies into incidents, tracks MITRE ATT&CK progression, and maps attack links chronologically.
- **Forensic IOC Extraction & Validation:** Detects, validates, deduplicates, and normalizes indicators across 9 standard types (IPv4, IPv6, Domain, URL, MD5, SHA1, SHA256, Email, File Path).
- **Reputation & Unified Threat Correlation:** Assesses threat severity independently from confidence and connects indicators to raw events, anomalies, incidents, and attack chains without mutating analyst triage states.
- **Enterprise Persistence & SOC Dashboard:** Multi-backend database architecture (In-Memory, SQLite, PostgreSQL) with a 15-route Next.js web application.

## 4. Project Scope

### Implemented Scope
- Multi-format log parsing (Syslog, Nginx/Web, SSH, Auth, Firewall, Application logs, CSV, TXT).
- Machine learning anomaly detection with Scikit-learn (Isolation Forest, TF-IDF semantic dispersion, Z-score).
- Multi-scale sliding window temporal intelligence (10s, 30s, 60s, 300s) with rate-of-change and burst detection.
- Incident derivation and MITRE ATT&CK chain reconstruction.
- Canonical IOC extraction, RFC normalization, and append-only evidence linking.
- Threat intelligence integration (Offline Mock Provider + VirusTotal Provider with rate-limiting and secret scrubbing).
- Threat reputation engine with deterministic scoring ($0–100$) and separate confidence ($0–1$).
- Directional threat correlation engine and `UnifiedThreatContext` generation.
- 12-table relational persistence architecture supporting in-memory, SQLite file, and PostgreSQL modes.
- Production-hardened REST API with FastAPI, custom error isolation, and readiness probes.
- 15-route responsive SOC Dashboard with Next.js 16, TypeScript, Tailwind CSS, and interactive graphs.
- Automated forensic PDF report generation.
- Comprehensive test harness: 412 backend tests (100% pass) and 15 statically verified frontend routes.

### Future Enhancement Scope (Planned / Non-Implemented)
- Continuous live stream ingestion via Apache Kafka or RabbitMQ.
- Real-time SOAR automated network isolation and firewall rule deployment (deliberately omitted to prevent unreviewed automated disruption).
- Distributed multi-node cluster deployment with Kubernetes operators.
- Support for proprietary threat feeds beyond VirusTotal (e.g., AlienVault OTX, MISP, CrowdStrike Falcon).
- Deep learning sequence modeling (e.g., LSTM, Transformer-based log embeddings).
