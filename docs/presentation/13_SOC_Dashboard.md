# Slide 13: SOC Dashboard & Investigation Experience

## Purpose-Built 15-Route Next.js Web Interface

---

### Key Points
- **Single-Pane-of-Glass Workspace:**
  - Executive Dashboard (`/dashboard`), Log Ingestion (`/logs`), Anomalies Queue (`/anomalies`), Incident Triage (`/incidents`).
- **Interactive Attack Chain Visualizer (`/attack-chains`):**
  - Directed acyclic graph showing intrusion progression across MITRE ATT&CK stages.
- **Dedicated Threat Intelligence Workspace (`/threat-intelligence`):**
  - Displays UnifiedThreatContext, reputation breakdown, signal points, and manual enrichment actions.
- **Forensic PDF Report Generator (`/reports`):**
  - Generates audit-ready compliance PDF reports in under 2 seconds.
- **Enterprise Build:** 15 static pre-rendered routes, zero TypeScript errors.
