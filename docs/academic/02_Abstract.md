# CHAPTER 2: ABSTRACT

Automated intrusion and anomaly detection in enterprise computing infrastructure is complicated by massive log velocity, extreme class imbalance, and the operational burden of alert fatigue in Security Operations Centers (SOCs). Traditional Security Information and Event Management (SIEM) tools rely primarily on static threshold heuristics that generate excessive false alarms while remaining vulnerable to stealthy zero-day exploits. Furthermore, when indicators of compromise are evaluated against external threat feeds, missing records are frequently misinterpreted as evidence of safety, creating severe false-negative vulnerabilities.

This research presents **MICHAEL – THE GUARDIAN AI**, an end-to-end intelligent log analysis, anomaly detection, and threat correlation platform. The architecture implements a hybrid multi-model detection engine that combines unsupervised Isolation Forest spatial isolation, TF-IDF semantic dispersion, statistical boundary estimation, deterministic heuristic rules, and multi-scale sliding-window temporal analysis ($10\text{s}$, $30\text{s}$, $60\text{s}$, $300\text{s}$). Detected anomalies are clustered into structured security incidents and synthesized into chronological attack chains aligned with the MITRE ATT&CK matrix.

An Indicator of Compromise (IOC) engine extracts, deduplicates, validates, and normalizes indicators across nine forensic categories (IPv4, IPv6, Domain, URL, MD5, SHA1, SHA256, Email, File Path) while maintaining append-only evidence links to exact raw log line numbers. External threat intelligence—integrated via an offline mock provider and a live VirusTotal API client—is evaluated by a deterministic Threat Reputation Engine that enforces strict telemetry deficit defenses ($\text{UNKNOWN} \ne \text{CLEAN}$) and decouples threat severity ($0–100$) from confidence ($0–1$). Directional correlations across all security entities form a consolidated `UnifiedThreatContext` presented through a responsive 15-route Next.js SOC workspace.

Evaluated under controlled synthetic validation environments, the platform achieved a 94.21% detection accuracy, sustained over 8,000 log events/sec bulk insertion into a 12-table relational persistence tier, passed a 12-vector security audit, and demonstrated zero data loss across process termination.
